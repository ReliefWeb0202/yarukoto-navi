# できそう！やることナビ (Task Breakdown App)

ユーザーが達成したい目標を入力すると、Gemini APIが自動的に具体的で実行可能なTODOリスト（アクションプラン）に分解・提案してくれるWebアプリケーションです。  
タスクの分解・スケジュール管理が苦手な人でも「これならできそう！」と思えるアプリを目指しました。

---

## 主な機能と特徴

- **Gemini AI による自動タスク分解**
  - 目標を入力するだけで、実行しやすいステップに分解して生成。
  - 「難易度（初心者向け／要点のみ）」「分解の細かさ（3〜5個／5〜8個／8〜12個）」「重点期間（準備／当日）」など、ユーザーの状況に合わせたプロンプト調整が可能。
- **カウントダウンタイマー ＆ 進捗可視化**
  - 目標期日までのカウントダウン表示（Safari互換対応）。
  - チェックボックスによるタスク消化と完了数のリアルタイム更新。
- **タスクの自由なカスタマイズ**
  - 手動でのタスク追加・テキスト編集・削除機能。
  - ボタン操作（▲▼）によるタスクの並び替え機能。
- **PWA（Progressive Web Apps）対応**
  - スマホやPCのホーム画面に追加して、アプリ感覚で利用可能（オフライン対応用Service Worker実装）。
- **安全なAPIキー管理**
  - ユーザー独自の Gemini API キーを使用し、ブラウザ内（LocalStorage）のみに安全に保存。
- **ダークモード対応**
  - 端末や好みに応じたカラーテーマ切り替え。

---

## 使用技術 (Tech Stack)

- **フロントエンド:** HTML5 / CSS3 / JavaScript
- **AI API:** Google Gemini API (`gemini-2.5-flash`)
- **Web API:** LocalStorage API / Service Worker API (PWA)

---

## 💡 開発におけるこだわり・工夫した点

AIが生成した順番だけでなく、直感的な並び替えをユーザーが自分の優先度に合わせて並び替えられるよう上下移動（▲▼）ボタンを搭載。
APIキーが未設定の場合や通信エラー発生時に、明確なエラーメッセージとAI Studioへの誘導導線を設置。
